# Project document prompts

| Document | Capture |
| --- | --- |
| Requirements | Actor, desired outcome, constraints, negative cases and acceptance criteria |
| Architecture and selection | Alternatives, responsibility boundaries, approved choice, migration and evidence |
| Design system | Approved brand, grids and breakpoints, token scales, themes, component states, accessibility and motion |
| API and database | Owners, versions, data contracts, schema constraints, migrations, grants and failure paths |
| Authentication, authorization and security | Actors, session lifecycle, resource permissions, threat boundaries, mitigations and negative tests |
| Testing and deployment | Environments, build/test commands, representative checks, configuration ownership, rollback and gaps |
| Change history | Effective change, affected users and contracts, evidence and migration or recovery notes |
