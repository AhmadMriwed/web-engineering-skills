# React engineering workflows

Use the project profile and [feature plan](../../assets/feature-plan.md) as inputs. For each change, record the affected files, decisions, documentation and checks. See [project documentation](../project-documentation.md) for the update triggers.

| Workflow | Preconditions and decisions | Sequence and placement | Rules, docs and validation |
| --- | --- | --- | --- |
| Initialize | Approved React profile, runtime, backend and host | Scaffold strict TS, lockfile and CI. Set up app config, providers and router, shared primitives and one feature slice. | WEB-DEC-001, WEB-ARC-001/002, WEB-QA-001. Create profile, architecture, structure, testing and deployment docs. Run clean install/build and route smoke. |
| Analyze, review architecture or refactor | Scope, existing profile, observed failures, migration approval when material | Inventory app entry, routes, feature imports, contracts and tests. Trace a flow, mark coupling, choose a boundary and stage the smallest behavior-preserving move. | WEB-ARC-001/002/003. Update architecture, structure and ADR if material. Compare behavior before and after, including existing caller interfaces. |
| Create feature, page or layout | Route, audience, acceptance criteria and access model | Add feature page, local components and hooks. Register route, add optional navigation, and compose nested layout in app. | WEB-ARC-001/002, WEB-AUTH-001. Update features, architecture when changed, and docs for route permissions. Check direct entry, focus, mobile nav and history. |
| Create shared component or hook | Stable contract, known callers and ownership | Keep private first. Extract UI to shared primitives or stateful behavior to a scoped hook. Define controlled props, ownership and cleanup, then migrate callers. | WEB-ARC-003, WEB-UI-001. Update design system or structure. Verify reuse, accessible behavior and subscription cleanup. |
| Integrate an API | Contract, scope, auth, limits and errors | Configure scoped adapter, declare feature models and service, decode data, expose query and mutation hooks, wire page states. | WEB-API-001, WEB-STATE-001. Update API and testing docs. Verify responses, cancellation and retries. |
| Build CRUD and validated forms | Permissions, routes or dialog, defaults, create/edit payloads and deletion semantics | Add feature schemas, service and mutations. Render labelled fields and confirmation. Map server errors, refresh exact caches and resolve pagination after writes. | WEB-FORM-001, WEB-API-001, WEB-AUTH-001. Update features and API docs. Verify create, edit, delete, duplicate submit, field errors and unauthorized calls. |
| Build dashboard and design system | Audience, branding assets, metrics, chart definitions and screen sizes | Define shared tokens and primitives, build shell, compose feature KPI and chart views with semantic fallbacks. | WEB-UI-001/003. Update design system, features and architecture. Verify themes, chart values, zoom, keyboard and motion. |
| Build table, search, filters, pagination and presentation states | Query contract, sort keys, page bounds, mobile layout | Create URL codec and list request, render a table or mobile cards, implement loading, empty, stale and error paths. | WEB-STATE-001, WEB-UI-002. Update features and API docs. Verify history, filter resets, retry, reflow, and last-page removal. |
| Implement authentication and permissions or review security | Credential contract, role/capability model, trusted origins and deployment | Compose session lifecycle, scoped client and guarded routes. Confirm API authorization, privacy of config, input and error handling. | WEB-AUTH-001, WEB-API-001. Update authentication, API and deployment docs. Verify deep links, expiry, account switch and negative permission cases. |
| Implement localization and RTL | Supported languages, fallback, direction, formatting | Register feature and common catalogs, set DOM language and direction, use logical layout properties and configure locale checks. | WEB-I18N-001 and WEB-UI-001. Update design system and features. Verify persistence, missing keys, RTL interaction and formatting. |
| Review performance or validate implementation | Baseline, target flows, deployment and test environment | Measure build and browser sequences, identify data and render costs, make scoped changes, rerun appropriate layers and deployed smoke. | WEB-PERF-001, WEB-QA-001. Update testing, deployment and limitations. Record actual results and exclusions. |
