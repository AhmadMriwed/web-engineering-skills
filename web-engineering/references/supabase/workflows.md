# Supabase engineering workflows

Start with the approved [project profile](../../assets/project-profile.md) and [backend plan](../../assets/supabase-plan.md). Apply WEB-DOC-001 to every row and WEB-DEC-001 to material decisions. Apply WEB-SUP-001 to schema and SQL changes and WEB-SUP-002 to every exposed resource. Routine implementation proceeds within approved scope. Obtain explicit approval before backend selection, provisioning, linking, destructive migration or production-impacting changes. Document evidence in TESTING and update FEATURES for changed user behavior. All workflows apply to the approved Supabase profile. The three application integration rows also apply the named [frontend or combined profile](applications.md). Reuse the frontend profile’s form, UI and deployment procedures. Use the file placement and validation gates in the [database](database.md), [identity](identity.md) and [services](services.md) references for operations that share a boundary.

| Workflow | Preconditions and decisions | Sequence and placement | Docs and acceptance checks |
| --- | --- | --- | --- |
| Initialize and configure local | Approved Supabase and runtime versions, isolated Docker and ports | Init, review config and env placeholders, start local stack, add synthetic seed under supabase | Profile, architecture, deployment. Clean start and two resets. |
| Connect existing project | Approved target and access scope, project owner, history and URL/key class | Inventory environments and migration ledger through approved read-only metadata, reconcile schema snapshot in isolation, configure typed client | Profile, database, migrations. Verify only synthetic test target and compatible schema. |
| Design schema and migration | Invariants, data classification, tenancy, existing consumers | Design keys and constraints, grants and RLS. Add unique migration, maintain upgrade and compatibility plan | Database, migrations, authorization, security and generated-type docs. Reset, upgrade, rehearse lock/recovery. |
| Regenerate types | Reviewed migrated schema and pinned CLI | Generate into temporary file, review, replace generated module, compile and diff in CI | Database and migrations. Strict shared consumer compilation and drift check. |
| Add feature or repository | Feature contract, access matrix, cache owner | Build feature repository and runtime decoder for untrusted data. Wire queries and UI | Features and API integration. Validate errors, cancellation, tenant switching and mapping. |
| Add CRUD or bulk write | Access and atomicity, duplicate semantics, audit | Use typed SDK for single operations and RPC for atomic multi-row operations. Scope invalidation | Database, authorization and features. Foreign rows, stale conflicts, replay and partial failure. |
| Search, filter and paginate | Allowed filters, size and stable order | Parse URL, enforce bounded queries, add indexes based on plans, choose offset or cursor | API and features. Boundary pages, count accuracy, empty states and large fixtures. |
| Implement authentication | Selected methods, redirect allowlist, session owner | Configure supported methods and lifetime; implement browser provider or request-scoped SSR, callbacks and logout | Authentication, deployment, security. Verify expiry, recovery, redirects and private cache clearing. |
| Implement authorization, RLS and tenancy | Actor/resource matrix, current membership, role policy | Create grants and policies in migrations, use tenant-consistent FKs, test as actual actors under supabase/tests | Authorization, database and security. Cover cross-tenant, revoked and changed-owner cases. |
| Implement Storage | Public/private, quota, lifecycle, allowed operations | Add bucket config and object policies, feature upload helper and metadata, retries and cleanup | Storage and security. Authenticated, anonymous, cross-owner, overwrite and interrupted upload. |
| Implement Realtime | Latency, fanout, sensitive payload and reconnect policy | Configure publication or private channels; place scoped hooks next to feature | Realtime and security. Check reconnect, duplicates, unauthorized subscribers and cleanup. |
| Implement SQL RPC or trigger | Transaction contract, privileges, locking and retries | Add reviewed SQL with explicit grants, typed inputs and bounded work | Database, migrations and authorization. Test rollback, concurrency and caller permissions. |
| Implement Edge Function | HTTP contract, caller, secrets, retry and idempotency | Put handler in supabase/functions, validate request and verified caller before privileged access, serve locally with synthetic secrets | Edge functions, API integration and security. Test auth, CORS, timeout and duplicate requests. |
| Integrate React | Approved SPA, environment and session owner | Follow SPA profile, compose auth once and wire scoped query cache | Architecture and authentication. Deep links, sign-out, user switching and mutations. |
| Integrate Next.js | Approved App Router version and runtime | Add SSR browser/server clients, refresh entry, route authorization and isolated render/cache | Architecture, authentication and deployment. Cookie refresh, SSR user isolation and build. |
| Integrate combined apps | Two app owners, migration owner and version policy | Share generated contracts; configure separate app environments and coordinate rollout | ADR, profile and deployment. Check version skew, callbacks and permissions independently. |
| Test policies and review security | Synthetic actors, production-like config represented locally | Reset, seed, test grant and RLS operations, Storage, RPC, subscriptions and elevated paths | Security and testing. Verify affected rows and independent services; record blocked checks. |
| Review performance | Representative load and metrics | Establish baseline, check plans, cache scope, connections and Realtime fanout, tune surgically | Database, deployment and testing. Compare latency, result correctness and write overhead. |
| Deploy and plan recovery | Approved release, availability, retention and RPO/RTO | Rehearse from prior release, schedule migration and consumer deploys, verify health, archive required backup, rehearse restore incl. stored objects | Deployment, migrations and changelog. Verify rollback compatibility and timed restore. |
