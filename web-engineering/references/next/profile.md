# Next.js App Router profile

Use for public, content-rich, SEO-oriented websites and for authenticated applications that benefit from server composition. Compare rendering, interaction, deployment and team needs with the React SPA in [project selection](../project-selection.md).

WEB-SRC-003 pins Next.js 16.2.4 and React 19.2.4, with TypeScript 5.9.3, next-intl 4.13.0, Tailwind 4.3.1, React Hook Form 7.80.0, Zod 4.4.3, native Fetch, motion and optional 3D UI. Dependency presence alone does not establish usage. Check the target's supported versions and host.
