# Example requests

Prefix a request with `$web-engineering` in Codex for explicit invocation. Claude Code documents `/web-engineering` after installation. Natural-language activation depends on the client and request.

| Task | Request |
| --- | --- |
| Internal dashboard | “Plan an inventory dashboard for staff. Compare stack options and ask about decisions that change the architecture.” |
| Public website | “Plan an English and Arabic service website with indexable detail pages. Help me choose its rendering strategy.” |
| Authenticated app | “Design accounts, bookings and support roles for a small scheduling app. Compare isolation and hosting options.” |
| Existing REST API | “Connect this stock screen to the supplied API contract and handle pagination and failure states.” |
| Backend discovery | “This project needs accounts and persistent drafts. Compare backend options and wait for my choice.” |
| Existing React feature | “Add warehouse filters to this React list using the current stack and conventions.” |
| Existing Next.js improvement | “Repair localized canonical links and verify the existing Next.js deployment mode.” |
| Migration | “Prepare a migration to add unique membership constraints. Identify unsafe existing data and test against a disposable database.” |
| Auth review | “Review resource authorization for this account page and report which actor checks are missing.” |
| Combined system | “Plan a public catalog and staff console sharing our API. Compare separate deployments with a single app.” |
| Backend-free landing | “Build a small product page with a contact CTA. Avoid infrastructure the requirements don't need.” |
| Documentation | “Update our project profile and deployment notes to match the implementation and actual checks.” |

For greenfield work, expect discovery and approval before material stack choices. For existing projects, provide the affected files and desired outcome. Treat example outputs and test claims as scoped to the project at hand.
