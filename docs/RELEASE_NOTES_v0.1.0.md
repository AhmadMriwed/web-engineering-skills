# Release notes for v0.1.0

Web Engineering Skills provides one installable skill for planning, building and reviewing React, Next.js and combined web applications. It includes external API guidance and optional Supabase integration, 20 stable engineering rules and 29 named task routes.

Start with project discovery and compare viable architectures before committing to a stack. Use the relevant workflow, template or neutral example during implementation. Existing projects retain their approved conventions.

Install the complete skill folder using the [installation guide](INSTALLATION.md). For example, ask Codex `$web-engineering Plan a multilingual public site and help me choose a rendering strategy.` See [more requests](USAGE.md).

Independent Codex CLI tests observed real project-local skill use. Selected frontend, API, browser and synthetic database checks passed. [Compatibility and limitations](PUBLIC_VALIDATION.md) distinguish package verification, agent behavior and managed-service gaps. Future work includes managed Supabase trials, Claude Code execution and broader browser and permission scenarios.
