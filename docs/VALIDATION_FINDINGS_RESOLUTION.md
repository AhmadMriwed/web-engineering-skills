## Comparative reconciliation

A/B discovery and B/F implementation have paired evidence. A enabled implementation and the remaining projects do not have comparable paired implementation evidence. The enabled A named a viable frontend and both A arms respected the API and actor constraints. B enabled identified search ambiguity, wrote a project profile, and passed an independent HTTP/browser probe. B control passed ten export tests and documented setup in its README. F enabled tested Escape in addition to close and reset; both variants retained dependencies. There is insufficient paired evidence of improved security.

CLI token totals were measured and higher in the reported enabled A/B discovery and B/F implementation pairs. These include system, cache and tool output; the sessions differed in visible work and experienced model/connector timing changes. Skill access was independently supported by file-read traces. These comparisons establish neither causal improvement nor a security or timing advantage.
